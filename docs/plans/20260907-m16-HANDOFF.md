## Facts learned today (not in the code)
- `pkill -f`/`pgrep -f` with a pattern that also appears in the CALLING command line kills/lists the
  caller (exit 144 twice today). Kill by explicit pid; when listing, keep the pattern out of the same
  command (`gat[e]` tricks do not help if the launch string is in the same shell line).
- bash `local a=$1 b=$(f $a)` expands `$a` BEFORE assigning it (unbound under `set -u`); split the `local`s.
  This made the salt-gate restart legs compare a directory with itself once — fixed, re-run, verdicts real.
- `diff_snap.py` needs `getfattr` (absent on GPU nodes): run snapshot diffs on the login node.
- The pi runs write a snapshot at step 0 as well: 20 steps / snap 10 ⇒ 3 files (gates must accept ≥2).
- nvcc gets only `-O3` (no `--use_fast_math`/`-ftz`): denormals are NOT flushed on the GPU (registry §1).
- CUDA DP vs Serial ref0 on pi: max|Δv| 3e-5 (atomic-scatter class); SP-CUDA vs DP-CUDA: u 5e-3.
- The stiffness drift instrument sees the defect at 200 steps that killed July's run at 118k
  (offdiag relL2 1.9e-7 → 1.25e-6, monotone).
