## 4. Traps this session paid for

- `/pool/data/...` is a **symlink into `/work/pd1284/...`** — a `/pool`-prefix guard never fires
  on a resolved path.
- Partitioner provenance is the md5 of **`libfesom_meshpart_C.so`**, not the executable; and the
  executable must be run **in place** (rpath `$ORIGIN/../lib64`).
- METIS 5.2.1: `i64=0` selects **64-bit**; its Makefile silently drops `cflags=`; its `-fPIC` is
  GCC-branch-only; GKlib installs to `lib64` while METIS reads `lib`.
- `local t=$1 o="$OUT/$t"` — bash expands **all** arguments to `local` before assigning, so `$t`
  is unbound. Fixed in four job scripts; it only ever "worked" where a loop variable of the same
  name existed in the caller.
- GitHub is reachable from the login node via `certifi` or plain `git`; bare `urllib` fails with
  `CERTIFICATE_VERIFY_FAILED` (and `curl` is broken account-wide).
