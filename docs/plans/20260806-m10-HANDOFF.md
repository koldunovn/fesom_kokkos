## 2. The results that stand

**⭐⭐⭐ Sergey's CG² instability is root-caused and cured.** `pr_values` is `D⁻¹C` with `C`
symmetric; the leading `1/d_i` (FESOM `solver.F90:79-80`, faithfully ported) breaks symmetry
(defect ratio 0.638). Every CG-CG variant replaces PCG's explicit `(p,Ap)` with a recurrence
valid only for symmetric `M⁻¹` ⇒ α wrong by **21.8 %** on CORE2, **18/20 solves diverge**.
Fix `M̃⁻¹ = D^{−1/2}CD^{−1/2}` ⇒ **0 fallbacks**. Plain CG survives (explicit α) but pays
**~7 %** in iterations (126 → 117) — so repairing `solver.F90` would speed up the EXISTING
solver too. PDFs for Sergey: `docs/report/m10_precond_note.pdf` (2 pp, with a Fortran patch)
and `docs/report/m10_typo_report.pdf` (T-1…T-9).

**⭐ Production result — CORE2 @ 512 CPU ranks (the production configuration):**
`cg2` −4.09 % · `oati` −5.28 % · **`pcsi` −6.30 %** whole-step; the solve itself −34/−47/−60 %.
Knee moves ×1.26–1.29 ⇒ 18–26 % more throughput at the same efficiency. Benefit switches on
around 300 vertices/core; below that (128/256 ranks) it is ≤1.7 %.

**GPU wins at ordinary node counts** — CORE2 1–16 nodes −5.2…−6.7 %, NG5 −2.3 %; SSH share is

## 3. 🔴 Retractions and process fixes — READ BEFORE TRUSTING ANY OLD NUMBER

Three separate contamination classes were found and fixed. **All three were caught by
internal inconsistency, not by a checker — assume more exist.**

1. **`sbatch --export` splits on COMMAS** ⇒ comma-separated knobs inside `LEGS` were truncated
   and job 26723783 measured the baseline against itself, reporting a plausible "+0.11 %".
   *Fix:* intra-leg separator is `+`; every leg echoes its resolved `FESOM_*` set.
2. **Tag collisions shared an output directory** (each job does `rm -rf "$OUT"`), so two
   concurrent runs interleaved logs and produced two different answers for the same 2048-rank
   config. *Fix:* `$OUT` now includes `$SLURM_JOB_ID`. The affected rungs were re-measured.
3. **❌❌ Fallback firings were not harvested.** EVERY farc leg on BOTH backends fired the
   guard (20–23 for `cg2`/`oati`, 4–6 for `pcsi`, ~7 % of solves) while being reported as a
   win. A leg with fallbacks is a variant/baseline MIXTURE, not an A/B point. *Fix:*
   `fallbacks=` is harvested per leg with a `[!! ] MIXTURE` warning. **No timing may be quoted
   without it.** All farc rows are VOID.

Also: `grep` needs `-a` on run logs (a NUL byte silently dropped a leg from a table).
