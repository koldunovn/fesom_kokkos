**The project's strongest gate certified, as bit-for-bit identical to ground truth, a lever that
deletes the sea ice.** On Serial `.d()` and `.h()` are the same memory, so all 55 deleted rails are
no-ops there — and the bug *was* a rail.

**The bug:** `Field::alloc()` zero-inits BOTH spaces and marks them `Synced`. The ice **initial
condition** is written **host-side** through the raw alias — the DualView never learns. **The only
thing that had ever carried that IC to the device was the per-step IN rail.** It *is* a pure round
trip between two device kernels — **on every step but the first.**

> 🔴 **RULE: before deleting a rail because "both sides are device kernels", ASK WHO PUT THE INITIAL
> VALUE THERE.** A per-step rail is often also, silently, the IC push.
> **NO SERIAL GATE CAN EVER VALIDATE A COHERENCE INVARIANT. The CUDA fidelity gate costs 42 seconds.**

## 6. Machinery added this session

- **`jobs/job_m7_ioacc_ssh`** — the eta_n/IOACC differential. The pattern generalises: **to test a
  device I/O resolver, toggle ONLY that knob within one binary and diff the file its output lands in**
  (`diff_snap.py --pattern '*.monthly.nc'`). ⚠️ Its automated verdict lines are WRONG by construction —
  they wire pass/fail to `diff_snap`'s **zero-tolerance** exit code on a **CUDA-vs-CUDA** comparison,
  which can never be byte-identical (atomics). **Read the ssh magnitude against the other fields' noise
  floor, not the rc.** *(A gate whose threshold a correct implementation cannot meet is its own trap.)*
- **`FESOM_DIAG_COEF`** (`fesom_jra55.cpp`) — prints `t_indx/rdate/lo/hi/need_refresh` for the
  getcoeffld guard.
- **`force:getcoeffld`** FPROF bracket — reports **calls/step**, the number that settled L82.

  said 34. **222.6 ms/step = 24% of the step is GPU-idle gaps >1 ms.** Recipe in the package-H doc.
